RTC 实时时钟

系统外设
掉电继续走时的日历时钟：日志时间戳、定时唤醒、低功耗设备的核心。
🧩 核心原理
  • 硬件日历：年/月/日/时/分/秒 + 闹钟/唤醒
  • 备份域供电：主电断开时由 Vbat 引脚电池供电，时间不丢
  • 时钟源：LSE 32.768kHz 晶振（1Hz 分频）或 LSI
  • 闹钟/唤醒：可产生中断或从停机模式唤醒
  • 备份寄存器：掉电保存少量数据（校准/标志）
  • 首次需校准：时间误差来源晶振偏差，可用 RTC 校准
📈 时序 / 工作过程图
⚙️ 配置 / 使用要点
  1. 使能 PWR/RTC 时钟，配置 LSE
  2. 设置日期时间（HAL_RTC_SetDate/SetTime）
  3. 配置闹钟/唤醒中断 + NVIC
  4. 读取：HAL_RTC_GetTime/GetDate
🛠️ 项目示例
RTC 定时唤醒低功耗（每分钟唤醒采集上报）
// 进入停机模式前配置唤醒定时器
HAL_RTCEx_SetWakeUpTimer_IT(&hrtc, 0x1FFF, RTC_WAKEUPCLOCK_RTCCLK_DIV16);
// 32.768k/16 = 2048Hz，0x1FFF=8191 → 4s

// 进入 STOP 模式
HAL_PWR_EnterSTOPMode(PWR_LOWPOWERREGULATOR_ON, PWR_STOPENTRY_WFI);

// 唤醒后：重新配置系统时钟 → 采集传感器 → 上报 → 再睡
void RTC_WKUP_IRQHandler(void){
  HAL_RTCEx_WakeUpTimerIRQHandler(&hrtc);
}
❓ 面试高频
RTC为什么断电还在走？
RTC模块和备份寄存器由Vbat引脚独立供电（纽扣电池/法拉电容），主电源断掉后仅RTC区域工作
RTC时钟源选LSE还是LSI？
LSE 32.768kHz精确（日历必须）；LSI约32kHz误差大，适合唤醒定时器
RTC时间误差怎么校准？
LSE晶振偏差(±20ppm)导致日误差约1.7s，可测实际偏差后用RTC校准寄存器补偿或软件周期校时
