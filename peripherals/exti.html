EXTI 外部中断

基础外设
引脚边沿触发中断，让 CPU 及时响应外部事件而无需轮询，是实时系统的关键机制。
🧩 核心原理
  • 触发方式：上升沿 / 下降沿 / 双边沿（可编程）
  • 每个 EXTI 线可独立屏蔽、独立挂起标志
  • 中断服务函数（ISR）要求：尽量短，只置标志位/清标志，处理放主循环
  • NVIC 优先级分组：抢占优先级 + 子优先级，决定中断嵌套行为
  • 唤醒：低功耗模式下外部中断可唤醒 MCU
  • 注意：共用一个中断向量号的 EXTI 线，需在回调里判断是哪一线
📈 时序 / 工作过程图
⚙️ 配置 / 使用要点
  1. 配置 GPIO 为输入并选择 EXTI 模式
  2. 选择触发边沿（HAL: GPIO_MODE_IT_RISING 等）
  3. 使能 NVIC：HAL_NVIC_SetPriority + HAL_NVIC_EnableIRQ
  4. 实现回调：HAL_GPIO_EXTI_Callback(GPIO_Pin)
🛠️ 项目示例
外部中断检测按键/传感器报警
// PE4 下降沿触发外部中断
gi.Pin = GPIO_PIN_4;
gi.Mode = GPIO_MODE_IT_FALLING;      // 下降沿触发
gi.Pull = GPIO_PULLUP;               // 默认高，按下拉低
HAL_GPIO_Init(GPIOE, &gi);

HAL_NVIC_SetPriority(EXTI4_IRQn, 1, 0);
HAL_NVIC_EnableIRQ(EXTI4_IRQn);

volatile uint8_t alarm_flag = 0;

void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin){
  if(GPIO_Pin == GPIO_PIN_4){
    alarm_flag = 1;        // ISR 只置标志，不做事
  }
}
// 主循环：
if(alarm_flag){ alarm_flag = 0; /* 处理报警逻辑 */ }
❓ 面试高频
中断服务函数里能做什么、不能做什么？
能：读寄存器、置标志、清中断标志。不能：长延时、printf、复杂运算——会阻塞其他中断导致响应超时
中断嵌套怎么实现？
NVIC 抢占优先级：高抢占优先级可打断低优先级中断；同抢占下按子优先级排队
共享变量在中断与主循环之间怎么保护？
加 volatile 修饰；多字节变量用临界区（关中断）保护，或使用原子操作
为什么不能直接在中断里做任务？
实时性会被破坏：其他中断被长时间阻塞、栈开销大、重入风险
