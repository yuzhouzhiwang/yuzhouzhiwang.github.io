# 硬件层 (Hardware Layer)

嵌入式系统的硬件基础层，涵盖芯片架构、硬件设计、电源管理、传感器技术、执行器控制与通信接口硬件等方向。

## 子板块

- [芯片架构](01-chip-architecture/) - ARM、RISC-V、AVR 等处理器架构
- [硬件设计基础](02-hardware-design-fundamentals/) - 电路设计、PCB 设计
- [电源管理](03-power-management/) - 低功耗设计、电源方案
- [传感器技术](04-sensor-technology/) - 各类传感器应用
- [执行器控制](05-actuator-control/) - 电机、舵机控制
- [通信接口硬件](06-communication-interface-hardware/) - UART、SPI、I2C 等

> 每个子板块按入门（beginner）/ 进阶（intermediate）/ 高级（advanced）三个难度组织内容。
