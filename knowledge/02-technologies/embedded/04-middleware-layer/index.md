## 学习路径

根据您的学习阶段，选择合适的学习路径：

=== "初学者路径"
    
    **学习重点**
    
    1. 从基础概念开始，理解核心原理
    2. 学习 **beginner** 级别内容，打好基础
    3. 完成基础练习和简单项目
    4. 逐步建立完整的知识体系
    
    **预计时间**：2-4 周

=== "进阶者路径"
    
    **学习重点**
    
    1. 深入学习 **intermediate** 级别内容
    2. 理解技术原理和实现细节
    3. 完成综合性项目实践
    4. 掌握常见问题的解决方案
    
    **预计时间**：4-8 周

=== "高级路径"
    
    **学习重点**
    
    1. 研究 **advanced** 级别的高级主题
    2. 深入源码和底层实现
    3. 解决复杂的实际问题
    4. 形成自己的技术见解
    
    **预计时间**：8-12 周

## 学习建议

!!! tip "学习方法"
    
    - **系统学习** - 按照子主题顺序逐步学习，构建完整知识体系
    - **实践验证** - 理论结合实践，通过项目巩固知识
    - **深度优先** - 在某个领域深入钻研，成为专家
    - **持续迭代** - 定期回顾和更新知识，保持技术敏感度

!!! info "难度说明"
    
    每个子主题都包含三个难度级别：
    
    - **beginner** - 入门级教程，适合初学者
    - **intermediate** - 中级进阶，需要一定基础
    - **advanced** - 高级实战，需要扎实的基础知识
