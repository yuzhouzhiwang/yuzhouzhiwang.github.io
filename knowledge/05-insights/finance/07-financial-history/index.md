# 金融历史（补充模块）

## 模块概述

历史是最好的老师。本模块回顾金融历史上的重大事件、危机和思想演进，帮助你从历史中学习规律和教训。

**学习时间**：可选扩展  
**文件数**：15+ 个  
**难度级别**：中级到高级

## 子模块

### [金融危机史](crises/index.html)
**文件数**：8 个

研究历史上的重大金融危机：
- 郁金香泡沫（1637）
- 南海泡沫（1720）
- 大萧条（1929-1939）
- 黑色星期一（1987）
- 亚洲金融危机（1997）
- 互联网泡沫（2000）
- 2008 金融危机
- COVID-19 市场崩盘（2020）

**学习重点**：理解危机的形成机制、传导路径和应对策略。
