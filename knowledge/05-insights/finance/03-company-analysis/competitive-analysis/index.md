# 竞争分析

## 模块概述

竞争优势决定企业的长期盈利能力。本模块将讲解波特五力模型、经济护城河等竞争分析框架，帮助你识别真正具有持久竞争优势的企业。

**学习时间**：1.5 周  
**文件数**：6 个  
**难度级别**：中级

## 核心主题

### [波特五力模型](porters-five-forces.html)
学习分析行业竞争格局的经典框架。

### [经济护城河](economic-moats.html)
**重点文件**：深入理解五种护城河类型（品牌、规模、网络效应、转换成本、成本优势）及 20+ 个公司案例。

### [竞争优势分析](competitive-advantage.html)
掌握识别和评估企业竞争优势的方法。

### [行业结构分析](industry-structure.html)
理解行业结构如何影响企业盈利能力。

### [SWOT 分析](swot-analysis.html)
学习全面评估企业优势、劣势、机会和威胁的方法。

## 学习建议

重点学习经济护城河，这是巴菲特投资哲学的核心。分析 10+ 家公司的竞争优势，建立识别护城河的直觉。
