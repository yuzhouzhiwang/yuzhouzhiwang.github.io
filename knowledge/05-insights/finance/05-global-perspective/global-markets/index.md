# 全球其他市场

## 模块概述

除了美国和中国，全球还有许多重要的投资市场。本模块将介绍欧洲、日本、新兴市场的特点和投资机会。

**学习时间**：1 周  
**文件数**：5 个  
**难度级别**：中级

## 核心主题

### [欧洲市场](europe.html)
研究欧洲主要市场和优秀企业。

### [日本市场](japan.html)
理解日本市场的特点和投资机会。

### [新兴市场](emerging-markets.html)
了解新兴市场的机会和风险。

### [市场对比](market-comparison.html)
对比全球主要市场的特征、估值和机会。

### [跨境投资](cross-border-investing.html)
学习跨境投资的方法和注意事项。

## 学习建议

理解不同市场的特点和差异，建立全球投资视野。重点关注欧洲的优秀企业和新兴市场的增长机会。
