# 中国医药健康行业

## 行业概述

中国医药健康行业受益于人口老龄化、消费升级和医保覆盖扩大，长期增长确定性高。行业包括创新药、仿制药、医疗器械、医疗服务等细分领域。

## 子行业

### [制药行业](pharma/index.html)
分析创新药和仿制药企业，包括恒瑞医药、药明康德等龙头公司，理解药品研发和商业化逻辑。

## 行业特点

- **强监管**：药品审批、集采政策
- **高壁垒**：研发周期长、投入大
- **刚需属性**：需求稳定增长
- **创新驱动**：从仿制到创新

## 细分领域

### 创新药
- **代表企业**：恒瑞医药、百济神州、信达生物
- **投资逻辑**：管线价值、研发能力
- **关键指标**：在研管线、临床进展

### 仿制药
- **影响因素**：集采政策
- **竞争格局**：价格竞争加剧
- **转型方向**：创新药、国际化

### CXO（医药外包）
- **龙头企业**：药明康德、康龙化成、泰格医药
- **商业模式**：为药企提供研发生产服务
- **增长驱动**：全球创新药研发外包

### 医疗器械
- **细分领域**：影像设备、耗材、IVD
- **国产替代**：进口替代机会
- **代表企业**：迈瑞医疗、联影医疗

### 医疗服务
- **主要业态**：医院、体检、眼科、牙科
- **商业模式**：连锁化、专科化
- **代表企业**：爱尔眼科、通策医疗

## 投资分析框架

1. **政策影响**：集采、医保目录
2. **研发管线**：在研产品价值
3. **商业化能力**：销售团队、渠道
4. **财务指标**：收入增长、研发投入、利润率
5. **估值水平**：PE、PS、管线估值

## 行业趋势

1. **创新药崛起**：政策支持、资本投入
2. **集采常态化**：仿制药降价
3. **国产替代**：医疗器械机会
4. **老龄化驱动**：需求持续增长

## 投资机会

- 创新药龙头（恒瑞医药）
- CXO 龙头（药明康德）
- 医疗器械（迈瑞医疗）
- 医疗服务（爱尔眼科）

## 风险因素

- 集采降价超预期
- 研发失败风险
- 政策变化
- 估值波动
