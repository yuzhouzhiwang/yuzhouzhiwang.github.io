# 美国制药行业

## 行业概述

美国制药行业是全球最大的药品市场，大型药企具有完整的研发、生产、销售体系。行业面临专利到期和定价压力，通过创新和并购保持增长。

## 主要企业

### 大型药企
- **Pfizer**：新冠疫苗、肿瘤药 → [案例研究](./pfizer.html)
- **Merck**：Keytruda（PD-1）、疫苗 → [案例研究](./merck.html)
- **Johnson & Johnson**：多元化医疗健康 → [案例研究](./johnson-johnson.html)
- **AbbVie**：Humira、免疫学 → [案例研究](./abbvie.html)
- **Bristol Myers Squibb**：肿瘤、免疫 → [案例研究](./bristol-myers.html)

### 专科药企
- **Eli Lilly**：糖尿病、肿瘤
- **Amgen**：生物药
- **Gilead Sciences**：抗病毒

## 商业模式

1. **研发创新**：新药开发
2. **专利保护**：独占期利润
3. **全球销售**：国际市场
4. **并购整合**：补充管线

## 行业趋势

1. **生物药崛起**：单抗、细胞疗法
2. **精准医疗**：靶向治疗
3. **定价压力**：政策监管
4. **并购活跃**：补充管线

## 投资机会

- 稳定现金流（Merck、AbbVie）

- 并购整合（Pfizer）
