# 美国科技行业

## 行业概述

美国科技行业是全球创新的引领者，涵盖云计算、半导体、软件等多个细分领域。FAANG（Facebook/Meta、Apple、Amazon、Netflix、Google）等科技巨头主导市场。

分析 AWS、Azure、Google Cloud 等云服务提供商，理解云计算的商业模式和竞争格局。

### [半导体](semiconductor/index.html)
研究 NVIDIA、AMD、Intel 等芯片企业，掌握半导体产业链和投资逻辑。

### [软件](software/index.html)
探索 SaaS、企业软件、安全软件等细分领域，分析 Microsoft、Salesforce、Adobe 等企业。

## 行业特点

- **创新驱动**：技术迭代快
- **高估值**：成长性溢价
- **赢家通吃**：平台效应
- **全球化**：国际市场重要

## 投资主线

1. **云计算**：数字化转型
2. **AI**：大模型应用
3. **半导体**：算力需求
4. **SaaS**：订阅模式
