# 实践指南

## 概述

本模块提供投资实践的具体指导，从开户到交易到记录，帮助你将理论转化为实践。

**文件数**：4 个  
**学习时间**：0.5 周

## 主题列表

### [账户开设](account-setup.html)
如何在不同市场开设投资账户

### [订单类型](order-types.html)
理解不同订单类型的使用场景

### [税务规划](tax-planning.html)
投资的税务考虑和优化

### [投资记录](record-keeping.html)
如何记录和跟踪投资决策

## 学习重点

- 选择合适的券商和账户类型
- 理解交易机制和成本
- 做好税务规划
- 建立投资日志
