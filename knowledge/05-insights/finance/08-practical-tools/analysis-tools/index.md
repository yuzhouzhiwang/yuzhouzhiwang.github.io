# 分析工具

## 概述

本模块介绍投资分析的实用工具，包括选股、估值、跟踪、数据、图表等工具。

**文件数**：7 个  
**学习时间**：1 周

## 工具列表

### [选股工具](../tools/screening-tools.html)
股票筛选和选股工具

### [估值计算器](../tools/valuation-calculators.html)
DCF 计算器、Excel 模板、Python 脚本

### [组合跟踪工具](../tools/portfolio-trackers.html)
投资组合管理和跟踪工具

### [财务数据源](../tools/financial-data-sources.html)
获取财务数据的平台和 API

### [图表平台](../tools/charting-platforms.html)
技术分析和图表工具

### [新闻聚合](../tools/news-aggregators.html)
金融新闻和信息聚合平台

### [研究平台](../tools/research-platforms.html)
投资研究和分析平台

## 使用建议

选择适合自己的工具组合，建立高效的投资分析工作流。工程师可以利用编程能力自动化部分分析流程。
