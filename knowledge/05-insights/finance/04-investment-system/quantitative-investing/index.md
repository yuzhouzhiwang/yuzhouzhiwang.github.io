# 量化投资

## 模块概述

量化投资使用数学模型和统计方法进行投资决策。本模块将讲解因子投资、统计套利、算法交易等量化方法，特别适合工程师背景的学习者。

**学习时间**：2.5 周  
**文件数**：12 个  
**难度级别**：高级

## 核心主题

### [因子投资](factor-investing.html)
理解因子投资的理论基础和实践方法。

### [Fama-French 模型](fama-french-model.html)
学习三因子和五因子模型的构建和应用。

### [动量因子](momentum-factor.html)
理解动量效应和动量策略。

### [质量因子](quality-factor.html)
学习如何量化企业质量。

### [价值因子](value-factor.html)
理解价值因子的定义和应用。

### [统计套利](statistical-arbitrage.html)
学习基于统计关系的交易策略。

### [算法交易](algorithmic-trading.html)
理解算法交易的原理和实现。

### [组合优化](portfolio-optimization.html)
学习马科维茨模型和组合优化方法。

### [风险模型](risk-models.html)
掌握量化风险管理的方法。

### [回测方法论](backtesting.html)
学习如何正确进行策略回测，避免过拟合。

### [量化基金研究](quant-funds.html)
研究成功的量化基金（Renaissance、Two Sigma、AQR）。

## 学习建议

量化投资需要数学和编程基础。工程师可以利用技术优势，学习如何将量化方法应用到投资中。建议结合 Python 代码实践。
