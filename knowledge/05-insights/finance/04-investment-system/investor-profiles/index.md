# 投资大师研究

## 模块概述

站在巨人的肩膀上学习。本模块深入研究 20 位顶级投资者的思想、方法和实践，涵盖价值投资、成长投资、宏观投资、量化投资等不同流派。

**学习时间**：2.5 周  
**文件数**：20 个  
**难度级别**：中级到高级

## 学习建议

### 学习方法

1. **对比学习**：对比不同投资者的方法和风格
2. **案例研究**：深入研究他们的经典投资案例
3. **思考适配**：思考哪种风格适合自己
4. **提炼原则**：提炼可以应用的投资原则

### 重点研究

建议重点深入研究 5-8 位投资大师：
- 价值投资：Buffett、Munger、Graham
- 成长投资：Fisher、Lynch
- 宏观投资：Dalio、Soros
- 风险控制：Howard Marks

## 学习检查点

- [ ] 研究了至少 10 位投资大师
- [ ] 理解不同投资流派的核心差异
- [ ] 找到了自己认同的投资理念
- [ ] 开始形成个人投资框架
