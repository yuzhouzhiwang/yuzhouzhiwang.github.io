LIN 汽车子网

工业总线
CAN的廉价补充：单线低速，车窗/座椅/灯控等车身子系统。
🧩 核心原理
  • 单线总线（+地），12V电平，最高 20kbps
  • 主从：一个主机节点 + 多个从节点
  • 帧：同步间隔(13位低) + 同步场(0x55) + PID + 数据 + 校验
  • PID 含奇偶校验位，数据场 0-8 字节
  • 调度表：主机按表轮询各帧（确定性）
  • 休眠/唤醒：总线命令实现低功耗
📈 时序 / 工作过程图
⚙️ 配置 / 使用要点
  1. 主机：定时发送调度表帧头
  2. 从机：检测同步间隔→同步场校准波特率
  3. 校验和：经典8位或增强(含PID)
  4. 波特率：9600/19200 常见
🛠️ 项目示例
LIN 帧头发送（主机）
// 主机发送帧头: 同步间隔(≥13位低) + 同步场0x55 + PID
lin_send_break();                 // 拉低 ≥13 位时间
send_byte(0x55);                  // 同步场：从机校准波特率
uint8_t pid = id | parity(calc(id));
send_byte(pid);                   // 受保护ID（含奇偶）
// 从机收到PID后决定响应数据或应答
❓ 面试高频
LIN为什么要同步场？
单线无独立时钟且允许低成本RC振荡器，从机用0x55的跳变沿校准自身波特率
LIN和CAN定位区别？
LIN单线20kbps成本最低，用于车身舒适性节点；CAN高速可靠，用于动力/安全网络
PID的奇偶校验怎么算？
P0 = ID0⊕ID1⊕ID2⊕ID4，P1 = ¬(ID1⊕ID3⊕ID4⊕ID5)，组成6位+2位校验
