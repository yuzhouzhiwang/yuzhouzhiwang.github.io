WiFi 无线局域网

无线协议
上云首选：内置TCP/IP栈，高带宽，智能家居/网关/摄像头主力。
🧩 核心原理
  • 802.11 家族：b/g/n(2.4G) / a/n/ac/ax(5G)
  • 嵌入式方案：ESP8266/ESP32、W5500以太网、AT指令模组
  • STA模式(连路由器) / AP模式(自己开热点) / AP+STA
  • 安全：WPA2/WPA3，企业网络需证书
  • 低功耗：DTIM睡眠/定时唤醒；但WiFi仍是耗电大户
  • 吞吐：2.4G 20-60Mbps 实测常见
📈 时序 / 工作过程图
⚙️ 配置 / 使用要点
  1. 配SSID/密码/安全类型
  2. DHCP 或静态 IP
  3. 连上后 TCP/UDP/MQTT/HTTP 通信
  4. 重连与断线检测：自动重连+状态上报
🛠️ 项目示例
ESP32 连接 WiFi + MQTT 上云（Arduino 风格）
#include <WiFi.h>
#include <PubSubClient.h>

const char* ssid = "Home_5G";
const char* pass = "********";

WiFiClient net;
PubSubClient mqtt(net);

void setup(){
  WiFi.begin(ssid, pass);
  while(WiFi.status() != WL_CONNECTED){ delay(500); }
  mqtt.setServer("iot.example.com", 1883);
  mqtt.connect("dev001", "user", "pass");
  mqtt.publish("dev/001/temp", "26.5");
}
void loop(){
  if(!mqtt.connected()) mqtt.connect("dev001");
  mqtt.loop();          // 保活+收消息
}
❓ 面试高频
WiFi为什么耗电大？
射频收发功耗高(峰值几百mA)、需保持连接保活；低功耗用DTIM睡眠或NB-IoT/LoRa替代
WiFi断线怎么处理？
状态机：检测断开→重连(指数退避)→失败上报；恢复后重订阅MQTT主题
AP和STA模式各什么用？
STA连家里路由器上网；AP自己发热点供手机直连配网/调试；AP+STA双模式实现中继
