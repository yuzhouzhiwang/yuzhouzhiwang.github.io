🔌 嵌入式常用外设速查
MCU 开发最常用的外设聚合：原理要点 · 关键参数 · 实战场景，面试与开发双用
💡 学习建议：面试问「外设」本质问三件事——怎么配置（寄存器/库函数）、什么参数（分辨率/速率/模式）、什么时候用（场景）。每个外设按「功能→参数→场景」记，配合开发板实操一遍即可讲透。
⚙️ 基础外设 GPIO / 中断 / 定时 / 转换 / PWM
🔢

GPIO通用输入输出

输入：浮空/上拉/下拉；输出：推挽(强驱动)/开漏(电平转换、I2C)。复用功能接外设。按键消抖、LED、读取状态最常见。

面试高频：推挽 vs 开漏 ⚡

EXTI外部中断

上升沿/下降沿/双边沿触发，按键唤醒、传感器报警。注意：中断里只做标志位，处理放主循环——避免阻塞与重入。

中断服务函数要短 ⏱️

定时器 TIM时基/捕获/比较

时基定时、输入捕获(测脉宽/频率)、输出比较(PWM)、编码器模式(测转速)。分频公式：定时时间=(ARR+1)×(PSC+1)/时钟频率。

分频计算必背 🎚️

ADC模数转换

逐次逼近型，12位常见。参考电压、采样保持、转换时间。实际电压 = ADC值×Vref/4096。多通道扫描+DMA搬运。

换算公式面试必问 📈

DAC数模转换

输出可调电压/波形(正弦/三角/锯齿)，音频、信号发生、基准源。注意输出驱动能力，带载需缓冲。

波形生成应用 🔄

PWM脉宽调制

频率+占空比两个维度：电机调速、LED调光、蜂鸣器、舵机(50Hz/1-2ms脉宽)。占空比=CCR/(ARR+1)。

舵机/电机必用
📡 通信外设 UART / SPI / I2C / CAN / USB / DMA
🔗

UART通用异步收发

异步全双工，TTL电平点对点。波特率常见 9600/115200，起始位+数据位+校验位+停止位。调试口、GPS、蓝牙模块。

异步=无时钟线 🔷

SPI同步串行外设

同步全双工，4线：SCK/MOSI/MISO/CS。主从模式，速率可达几十MHz。Flash、SD卡、显示屏、传感器。

CS片选=一从一选 🔸

I2C集成电路总线

同步半双工，2线：SCL/SDA，开漏+上拉电阻。7/10位地址寻址，速率 100k/400k/1M/3.4M。EEPROM、传感器、RTC。

开漏必须有上拉 🚌

CAN控制器局域网

差分总线，多主，报文ID仲裁，错误处理强。汽车/工业总线。标准帧11位ID、扩展帧29位。1Mbps@40m。

汽车电子必备 🔌

USB通用串行总线

主机-设备，枚举+端点通信。设备类：CDC虚拟串口/HID/大容量存储。D+上拉识别，12M全速/480M高速。

ST-Link就是CDC 💨

DMA直接内存访问

外设⇌内存数据直传，不占CPU。ADC多通道采集、UART收发、内存拷贝。注意内存对齐与传输完成中断。

高吞吐必备
💾 存储与系统外设 Flash / EEPROM / SD / 时钟 / 看门狗 / RTC
💾

Flash片内程序存储

存程序与掉电数据，按扇区/页擦除后写。擦写寿命约1万次，地址对齐。IAP在线升级原理基于此。

先擦后写 🧠

EEPROM掉电保存

按字节擦写，寿命百万次，保存配置/校准参数。片内EEPROM或I2C外挂(AT24Cxx)。参数掉电不丢。

存配置参数 💳

SDIO/SD存储卡

SD卡/MMC，1位/4位总线，配合FATFS文件系统。数据记录、日志存储、固件升级包。

配文件系统使用 🕐

RCC时钟树

系统时钟源头：HSE晶振→PLL倍频→AHB/APB分频。外设时钟开关省电。改时钟=重新配置所有外设分频。

时钟树要会画 🐕

看门狗IWDG/WWDG

程序跑飞/死循环时复位系统。IWDG独立时钟不可关，WWDG窗口期喂狗。生产环境必开，防止设备死机。

防止死机 📅

RTC实时时钟

年/月/日/时/分/秒+闹钟+唤醒，低功耗待机唤醒。备份域供电断电走时。日志时间戳、定时唤醒。

低功耗唤醒
