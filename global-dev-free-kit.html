独立开发者穷鬼套餐（全球版）

国内版广受好评之后，全球版来了：全靠免费额度，把产品跑起来
工具成本：0 元（无月费，收款按成交抽成）
1AI 全家桶
0 元
AI 编程：Copilot / Cursor / Cline
Copilot Free 每月 2000 次补全加 50 次对话；Cursor 免费版可用；开源的 Cline 能对接 Groq 或 Gemini 的免费 API，实现零成本 AI 编程。
提示：三个换着用，Cline + Groq 跑轻量任务，省下贵的额度。
AI 助手：ChatGPT / Gemini / Claude
网页版都能免费用，写文案、调代码、做产品方案都够；Logo 和宣传图直接用它们自带的生图能力。
提示：轮换用三家免费额度，回答质量和侧重点互补。
2代码与部署
0 元
代码管理 + CI/CD：GitHub
私有仓库免费，公开仓库跑 Actions 也免费，个人项目的自动构建和部署够用。
提示：开源项目公开仓库，CI 额度更宽裕。
部署 + CDN：Cloudflare / Vercel
静态站和全栈应用都能部署，带宽不限量，允许商用。Vercel 免费版有 100GB 带宽和 100 万次函数调用，Next.js 项目部署体验最好。
提示：全栈上 Vercel，全球加速上 Cloudflare，两者可以配合。
域名 + SSL：Cloudflare
部署到 Cloudflare 自动分配子域名，SSL 证书也自动配好，域名和证书一分钱不花。
提示：后期要自定义域名，在 Cloudflare 上绑定并托管 DNS 即可。
3数据与存储
0 元
数据库 + 认证：Supabase
开源的一站式后端平台，免费 500MB 数据库存储，自带用户认证、文件存储和实时订阅，适合全栈项目。
提示：实时订阅做聊天、通知类功能很省事。
存储 + 缓存：Cloudflare R2 + Upstash
R2 对象存储免费 10GB 且出口流量免费；Upstash 的 Serverless Redis 免费版 256MB 加每月 50 万次命令，做会话管理和接口限流够用。
提示：R2 出口免费，图片和文件都往里放；Upstash 管限流和缓存。
4运营分析
0 元
用户行为分析：Clarity
微软出品，录屏回放、热力图、点击检测全都免费，真的不限流量、不限站点数，做产品优化必备。
提示：录屏回放能看到用户真实操作路径，改版前先看一遍。
流量统计：Google Analytics
完全免费，功能最全，转化、留存、渠道分析都覆盖。
提示：Clarity 看行为，GA 看漏斗，两个一起埋。
错误监控：Sentry
自动捕获前后端报错，免费版每月 5000 个错误事件，几行代码就能接入。
提示：配好 Source Map，报错直接定位到源码。
产品趋势：Google Trends
验证产品方向时先用它看搜索趋势和市场热度，完全免费，立项前的低成本调研。
提示：对比几个关键词的相对热度，再决定先做哪个方向。
5办公与收款
按成交抽成
设计工具：Figma
UI 设计行业标准，免费版草稿箱里的文件不限量，可多人协作的设计文件有 3 个，一个人画原型做界面够用了。
提示：个人项目用草稿箱存文件，3 个协作位留给临时协作者。
邮件发送：Resend
开发者邮件发送服务，免费版每月 3000 封、日限 100 封，API 简洁好用。
提示：日限 100 封，发验证码注意别集中在同一天。
收款：Lemon Squeezy / Creem
卖数字产品或 SaaS，最省事是找 MoR（商户记录）平台，让它以卖家身份帮你处理全球税务和合规，不用自己注册海外公司，两家都没有月费，卖出去东西才扣手续费。
提示：有销售才抽成，适合做小规模数字产品试水。
