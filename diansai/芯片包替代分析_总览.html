本页在已有 6 款主选 MCU 体系基础上，纳入芯片包新增的低功耗档与通用/高性能档芯片，逐款评估其对现有 PRD 主控选型池的替代可行性、软件移植成本与供应链成本，作为 163 题 PRD 体系主控选型的扩展依据。

一、分析结论摘要

19 款可评估主控按替代可行性分为三层，三色标签与下文大表结论列一一对应：

【可直接替代】

pin-to-pin 或同库体系，PCB 基本不改 / DDL 同风格，移植成本低。

清单：CS32F030C8T6（pin-to-pin 替 STM32F030）、HC32F030（小华同族 F 系）、CW32F030（对标 F030，标准库风格接近）、GD32E230（对标 F030）、HC32L130→HC32L13x（同族超低功耗升级）。

【可替代需移植】

同档定位但内核 / 寄存器 / 外设超集不同，需重新配置时钟树、外设与链接脚本。

清单：STM32F103→GD32F407/STM32F407（M3→M4F 需移植 + FPU 加速）、HC32F005→HC32F072（外设超集需重配）、MM32L0020→CS32L010/HC32L110（低功耗同档需移植）。

【定位补充】

不构成 pin 替代，而是补全现有选型池未覆盖的档位（大存储低功耗 / USB / TI 生态 / 高性能基准）。

清单：HC32L17x / L19x（大存储低功耗档）、HC32L07x（Crystal-less USB 低功耗）、MSPM0G3507（TI 生态 / 电赛赞助）、STM32F407（CubeF4 高性能档基准）。

风险提示："能亮灯 ≠ 迁移完成"。跨厂商替代须检查 8 处隐藏差异（器件型号/启动文件/链接脚本、时钟树 PLL、Flash 扇区布局、擦写等待周期、外设寄存器语义、ADC 校准/采样/参考电压、烧录算法/IDCODE/UID 地址、产线烧录与校准工具），并经 4 轮验证（工程下载→功能→性能可靠性→量产）后方可进入正式 BOM。

三、分档替代路线图

按 低功耗档 / 通用入门档 / 高性能档 三档给出替代路线，评估维度涵盖：pin 兼容性、外设覆盖、开发生态、BOM 成本、认证与供货。

低功耗档 电池 / 表计 / 便携测量

MM32L0020（Standby 0.35μA）→ CS32L010 / HC32L110（同档替代，需移植）→ HC32L13x（0.5μA+LCD，升级）→ HC32L17x / L19x（128K/256K 大存储低功耗）

路线要点：现有 HC32L130 可直接升 HC32L13x（同 DDL）；MM32L0020 极致低功耗走 CS32L010/HC32L110 同档替代（需重配低功耗模式与唤醒源）；需 LCD+大 RAM 上 L17x/L19x；需 USB 上 L07x。低功耗档国产成本优势明显，认证以工业级 -40~85℃ 为准。

通用入门档 电源 / 传感 / 工业信号链

STM32F030（生态基准）→ CS32F030（pin-to-pin 直替）→ CW32F030 / GD32E230（对标 F030 国产替代）→ HC32F030（内置 3OPA+2DAC+VC 模拟增强）

路线要点：F030 这一档是国产替代最成熟的区间——CS32F030 pin-to-pin 可直接换板；CW32F030/GD32E230 为第二供货源（标准库/FWLib 风格接近，需核对时钟树与 Flash 等待周期）；需内置模拟前端省外部运放时上 HC32F030。HC32F005（SOP20 小封装）→ HC32F072（外设超集+CAN/USB）做引脚升级时需重新配置。

高性能档 复杂算法 / 通信 / 图形

STM32F103C8T6（M3 72MHz 兜底）→ GD32F407 / STM32F407（M4F 168MHz FPU）→ MSPM0G3507（TI 80MHz 双ADC 生态补充）

路线要点：M3→M4F 属跨内核升级，必须移植并启用 FPU 加速浮点算法；GD32F407 为 F407 国产对标（FWLib，需重配 HAL/链接脚本），STM32F407 保留 CubeF4 高性能基准与竞赛标杆地位；MSPM0G3507 走 TI DriverLib，生态独立，用于 TI 赞助题与高可靠工业场景，不参与国产替代切换。

四、两阶段策略回顾

本芯片包替代分析延续《选型策略总览 V2.0》的两阶段策略，在芯片层面落到具体路线：

1阶段一：成熟方案先行（保进度）

  • MCU：STM32F030 / F103 / F407 生态，MSPM0G3507（TI 赞助系）
  • 目标：快速验证 163 题方案，资料/调试支持最充分
  • 本包对应：StdPeriph/CubeF1/CubeF4/DriverLib 基准料

2阶段二：国产化替代（降本/供应链安全）

  • MCU：CS32F030 / HC32 全系 / CW32F030 / GD32E230·F407
  • 目标：BOM 降 30~50%，供应链自主可控，避免进口断供
  • 本包对应：pin-to-pin 直替 + 同库迁移料，经 4 轮验证后切 BOM
切换原则：国产替代必须经功能/性能/高低温/长期稳定性验证；PCB 按兼容封装预留；高精度测量与安全相关器件谨慎替代。

五、软件库跨 MCU 复用说明

以下 5 个软件库跨厂商复用，不绑定单一 MCU，是替代迁移时"业务代码可继承"的关键。SDK 版本以芯片包总索引.md 为准。

软件库版本适用场景跨 MCU 复用要点
LVGLv8.3.11带 LCD/屏的题：便携仪表、图形界面资源占用低，跨 MCU；需移植显示驱动与输入驱动到具体屏接口；适合 HC32L13x/L17x/L19x/L07x（内置 LCD）与 HC32F072
RT-Thread嘉立创 DAPLINK 工程版多任务复杂业务、组件丰富需求国产 RTOS，需 ≥8K SRAM；BSP 需按目标 MCU 移植；适合中高性能档（F407/HC32F072）
FreeRTOS10.4通用 RTOS，内核小巧全球生态最广，M0+/M3/M4F 通用；移植只需提供 Port 层（栈/中断），业务任务可继承；替代迁移首选 RTOS
CherryUSB0.10.2需 USB 设备/主机的题国产 USB 协议栈，设备+主机、零拷贝；需目标 MCU 带 USB 外设：HC32L07x（Crystal-less USB）/ HC32F072 / STM32F103·F407
CMSIS取自 STM32F103 HAL 工程所有 Cortex-M MCU 的内核基石ARM 内核标准头文件/NVIC/ intrinsic，跨全部本包 MCU（M0/M0+/M23/M3/M4F），不绑定厂商；替代迁移时内核层天然兼容

复用结论：CMSIS + FreeRTOS + LVGL + CherryUSB 构成"与厂商无关"的业务中间件层；替代迁移主要工作量在厂商 DDL/HAL 适配层（时钟树/GPIO/外设寄存器），业务逻辑与 RTOS 任务可最大程度继承。
