4.3 非功能需求（NFR）

  • 成本：量产 BOM 目标 ≤ 50 元（按题目复杂度调整）；
  • 可靠性：连续满载运行 2h 不失效，关键器件温升 ≤40K；
  • EMC：按 GB/T 17626 摸底，入口加滤波与保护；
  • 可维护性：关键参数可校准并存 EEPROM/Flash，固件预留升级通道。

6硬件设计要点

6.1 系统硬件方案

  • 采用 power 类通用硬件架构：信号输入/功率级 → 信号调理/ADC → MCU控制 → 驱动/输出 → 电源管理；
  • MCU 优先选用国产本地芯片（详见 §6.2），模拟前端/电源管理/驱动/信号链沿用 TI/ADI 元器件（以原厂数据手册为准）；
  • PCB 按 2 层板设计（复杂题目可 4 层），模拟区与数字区分区布局，关键信号线做阻抗控制与屏蔽。

7.3 关键算法

  • 采样与滤波：多次平均+滑动窗口滤波，抑制噪声；关键参数用中值滤波去毛刺；
  • 控制算法：数字 PI/PID 控制（如适用），采样周期 1~10ms，输出限幅防饱和；
  • 标定与补偿：两点/多点法校准，校准系数存 EEPROM/Flash，CRC 校验；
  • 低功耗管理：空闲时进入低功耗模式，外设时钟按需使能，电池供电产品重点优化。

12附录

12.1 关键公式

  • 采样换算：物理量 = (ADC_code × V_ref / 2^N − V_os) / G，N为ADC位数，G为前端增益；
  • 控制环：输出 += Kp×(设定−实测) + Ki×积分，输出限幅防饱和；
  • 效率（电源类）：η = P_out / P_in × 100%；
  • 精度：误差 = |实测 − 标准| / 满量程 × 100%。
