简易直流电子负载（源自 2012 全国大学生电子设计竞赛 C 题）

本文档将竞赛题目转化为公司研发立项形式：定义产品需求、系统方案、硬件/固件设计要点、测试验收标准与交付物，供研发人员据此开展设计。电子负载——电源厂/电池厂测试必备设备方向。

2立项依据与市场场景

2.1 立项价值

以赛题为原型，搭建公司在「电子负载——电源厂/电池厂测试必备设备」方向的技术能力平台，沉淀可复用的信号链/功率链/控制链模块，一次开发、多产品线复用，同时作为新员工培养与硬件/固件协同验证载体。

2.2 市场与客户场景

方向典型产品/场景客户诉求对系统的要求
工业电子电源/电池厂测试CC/CV/CR 模式恒流闭环
测试仪器直流电子负载可编程、高精度低纹波
研发电源老化/验证快速拉载散热设计

2.3 范围决策

V1.0 聚焦赛题核心指标保底，并按公司化要求对精度/效率做 1.5 倍裕量自测；标注 消费 / 工业 / 车规 方向差异，一套硬件覆盖主要方向。

6硬件设计要点

6.1 主电路

  • 功率 MOS 工作于线性区作恒流吸收；运放构成 CC 环：DAC 设定 → 误差放大 → MOS 栅极 → 采样电阻反馈（TI 电子负载参考设计）；
  • 大功耗需散热器+温控风扇，过热保护。

6.2 采样与设定

  • 电流低边采样（小阻值）+ INA240 放大；电压采样分压；DAC8562 设定恒流值（10mA 分辨率）。
