2项目背景与立项依据

2.1 立项价值

以赛题为原型，搭建公司自有「应变式称重信号链」能力平台：应变片全桥 → 仪表放大/PGA → 高精度 Δ-Σ ADC → MCU（滤波、标定、算法）→ 显示/报警/通信。该信号链是电子秤、体脂秤、工业称重配料、压力检测工装等产品线的公共底座，一次开发、多线复用；同时作为新员工与硬件实习生的培养载体。

2.2 市场与客户场景

方向典型产品 / 场景客户诉求对信号链的要求
消费电子厨房秤、体脂秤、便携电子秤低成本、颜值、低功耗、蓝牙1g 分辨率、低成本方案、待机省电
工业电子称重配料、物流复核、实验室微量秤、产线检重工装精度与重复性、抗干扰、可校准0.1g 分辨率、多点标定、抗温漂/振动
车规（远期延伸）座椅压力感知、扭矩/载荷监测车规级可靠性、AEC-Q100高可靠信号链 + 冗余设计（本版本不涉及）

2.3 立项范围决策

V1.0 聚焦量程 5.00~500g、显示分辨率 0.01g 的高精度小型电子秤整机，同时验证两种产品形态：消费形态（键盘+屏显，可选蓝牙）与 工业形态（UART 数据输出 + 校准模式），一套硬件覆盖两个方向。

3产品定位与范围

3.1 产品定位

低成本、高分辨率、可标定的台式电子秤模组/整机，面向厨房称重与实验室/产线微量称重场景，兼具「竞赛指标保底 + 公司化指标加严」的双重验收。

3.2 In Scope / Out of Scope

范围包含
In称重结构（悬臂梁+全桥应变片+秤盘）、信号调理与 ADC、MCU 主控、显示、按键、超量程报警、电源、校准模式、UART 输出（可选蓝牙）；配套固件、标定 SOP、测试报告、说明书
Out贸易结算类秤的法定计量认证（OIML/型式批准）、远程云平台、大称量工业台秤（>5kg）、车规量产认证

4.3 非功能需求（NFR）

  • 成本：量产 BOM（含传感器与结构件）目标 ≤ 30 元人民币；
  • 可靠性：按键 ≥10 万次；传感器过载 150%FS 无永久损伤；
  • EMC/ESD：接触放电 ±4kV（按 GB/T 17626.2 摸底）；
  • 可维护性：固件预留 IAP/OTA 升级通道；校准参数存 EEPROM/Flash 并支持恢复出厂；
  • 法规合规（内部约束）：本产品不作为贸易结算秤销售，不做强制计量认证。

6硬件设计要点

6.1 称重传感器与结构

  • 传感器：电阻应变式全桥称重传感器，量程 0~5kg，灵敏度典型 1mV/V（若量程 0~1kg 亦可，保证 500g 工作点在量程 50% 附近线性最佳）；
  • 结构：铁质悬臂梁固定于支架，支架高度 ≤40cm，秤盘与支架材质/形状不限但需保证：加载点一致、梁端不碰壁、过载有限位；
  • 粘贴工艺（关键工序）：打磨 → 丙酮清洁 → 定位贴片 → AB 胶固化（24h）→ 引线焊接 → 硅胶防护；每片贴后做桥路平衡测试并记录初始零点，建立粘贴 SOP。

6.2 信号调理与 ADC 选型（多方案对比）

方案厂商位数 / PGA典型噪声（RMS）接口参考价适用
HX711国产（海芯）24bit / ×64×128±0.5µV 量级（称重专用）两线串行≈1 元V1.0 首选：成熟、易得、资料多、低功耗
ADS1232TI24bit / 可编程增益低噪声，桥式传感器专用SPI≈10 元备选：对标称重设计，TI 生态
AD7190ADI24bit Σ-Δ / 1~12811nV/√Hz，称重专用SPI≈25 元升级项：工业高精度版本

V1.0 结论：主方案 HX711（成本与供货最优）；PCB 预留 ADS1232 兼容位（同封装/引脚可替换评估），便于后期按噪声、温漂指标升级。

6.3 噪声预算（关键计算）

环节数值说明
满量程桥输出5kg × 1mV/V × 5V = 25mV（桥满量程）500g 工作点输出 2.5mV
500g 对应 ADC 输入2.5mV × 128 = 320mVPGA ×128 后
0.1g 对应电压320mV / 5000 = 64µV（ADC 输入）分辨率目标 0.01g → 6.4µV
ADC 量化320mV / 2^24 ≈ 19nV LSB量化远小于目标，受限于前端噪声
噪声裕量有效噪声需 < 6.4µV（对应 0.01g）用 10~20Hz 低通 + 多次平均实现

6.5 电源 / 显示 / 按键 / 报警

  • 电源：USB 5V 或 3.7V 电池 → LDO 3.3V（如 AMS1117-3.3 或 TI TPS7A 低功耗系列）；桥激励由 3.3V 经 RC 滤波后供给；
  • 显示：I2C 0.96" OLED（128×64）或 LCD1602；显示布局：重量（主）、单价、金额、去皮指示、超重提示；
  • 按键：4×4 矩阵（0-9 数字、单价、去皮、清零、校准进入/退出）；按键扫描 10ms 防抖；
  • 报警：有源蜂鸣器，GPIO 驱动，超量程持续 1s、欠量程短鸣 2 声。

6.6 DFM 与布局要点

  • 桥路走线差分等长，S+ / S- 用屏蔽线并单点接地；
  • ADC 与 MCU 分电源分区，蜂鸣器/PWM 远离模拟区；
  • 关键位预留 0Ω 电阻用于噪声调试；传感器接口使用可插拔端子，便于换传感器；
  • 过载保护限位结构在机械设计中落实（防 150%FS 应变片损伤）。

7.2 主流程（伪代码）

初始化：时钟 / GPIO / ADC / OLED / EEPROM 读标定参数（k、b、零点 AD） 循环 { 采集 16 次 AD → 中值 + 滑动平均（窗 N=10） 重量 = (AD - 零点AD) × k // k = 满量程g / 满量程AD差 若去皮有效：重量 -= 去皮重量 稳定判定：连续 5 次 |Δ| < 0.01g → 显示锁定 超量程(>500g) → 报警 + "超重"；欠量程(<5g) → 显示 0.00 按键扫描（10ms 防抖）→ 去皮 / 单价 / 清零 / 进入校准 显示刷新（10Hz）；UART 帧发送（工业形态）

7.3 关键算法说明

  • 滤波：16 次采集先中值滤波剔除粗差，再做 N=10 滑动平均，等效约 20Hz 低通，满足 0.01g 稳定显示；
  • 标定（两点法）：空载记录 AD0，加载已知 100g 记录 AD1 → k = 100/(AD1-AD0)，b = AD0；精度不满足时可做 5 点分段标定；
  • 去皮：按去皮键后记录当前重量为去皮值，此后显示 = 当前重量 − 去皮值；再按清零恢复；
  • 计价：单价(元/g) × 净重 = 金额；累计 = 前次累计 + 本次金额，支持清空；
  • 校准入口：长按「清零」3s 进入工程模式（需密码 0000），按提示依次放砝码。

7.4 校准 SOP（量产/现场）

  1. 整机通电预热 5 分钟，空载清零；
  2. 进入校准模式，先记录空载 AD0；
  3. 放 100g 标准砝码，记录 AD1，自动计算 k；
  4. 放 500g 验证误差，不合格重新校准或检查传感器粘贴；
  5. 参数写入 EEPROM，标记校准日期与序列号。

12.1 关键公式

  • 重量换算：W(g) = (AD − AD₀) × k，k = 标定砝码重量 / (AD₁ − AD₀)；
  • 桥输出：Vout = 灵敏度(mV/V) × 激励(V) × 载荷/量程；
  • 显示分辨率校验：ADC 输入电压变化(0.01g) ≥ 前端有效噪声 × 6（工程裕量）。
