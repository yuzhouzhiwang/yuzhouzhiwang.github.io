## 一、本次做了什么

1. **20 款芯片包逐一评估**（19 款主控 + SDK 条目）——生成公司化总览页《芯片包替代分析_总览.html》，结论分三层：
   - **可直接替代**：CS32F030C8T6（pin-to-pin 替 STM32F030）、HC32F030、CW32F030、GD32E230（对标 F030）、HC32L130→HC32L13x（同族超低功耗升级）
   - **可替代需移植**：STM32F103→GD32F407/STM32F407（M3→M4F）、HC32F005→HC32F072（外设超集）、MM32L0020→CS32L010/HC32L110（低功耗同档）
   - **定位补充**：HC32L17x/L19x（大存储低功耗）、HC32L07x（USB 低功耗）、MSPM0G3507（TI 电赛赞助系）、STM32F407（CubeF4 高性能档）
2. **163 份 PRD 选型表全量扩展（V2.2）**：每份按题目档位追加「V2.2 扩展档」表格——
   - 低功耗类（无线/便携/电池供电，33 份含双档位）→ HC32L110 / HC32L17x / CS32L010
   - 高性能类（电机控制/图像/高速采集，60 份含双档位）→ GD32F407 / STM32F407（M4F 168MHz FPU）
   - 通用入门类（74 份）→ GD32E230 / CW32F030 / MSPM0G3507 / HC32F030
   - 保留公司化×电赛双视角理由；选型策略 note 升级为「V2.2·芯片包替代性检查」并注明详见《芯片包替代分析_总览.html》
3. **四向互访**：index.html（橙色「芯片包替代分析 V2.2」徽章）、PRD_总览.html（nav 链接）、选型策略_总览.html（nav 互链）、替代分析页内回三处链接。
