独立开发者穷鬼套餐

从写代码到上线运营，14 项工具全覆盖，额度、用法、避坑一次讲清
全年总成本：29 元（仅域名）
1AI 全家桶
0 元
AI 编程：Trae / 通义灵码 / Copilot
Trae（字节出品）和通义灵码（阿里出品）个人版免费、国内直连，Copilot 免费版每月 2000 次补全。三个换着用，日常写代码基本不花钱。
提示：Trae / 灵码做主力，Copilot 只在需要时开，别浪费每月补全次数。
AI 大模型：百炼 / 智谱 / 豆包
阿里云百炼新用户送 7000 万 Token（90 天有效）；智谱送 2000 万 Token 且 GLM-4-Flash 长期免费；火山豆包系列每个模型 50 万 Token。轮着薅，几千万 Token 够一个产品从开发到上线。
提示：额度按模型分开算，注意有效期；上线后盯一下每日消耗，防一夜烧光。
AI 设计：即梦 / 可灵 / 豆包
即梦每天登录送 60-100 积分，可灵每天有免费生成额度，豆包网页端基础生图免费。Logo、宣传图、配图都能搞定。
提示：文案里标中文用引号，生成效果更稳；导出后可用即时设计再加工。
2代码与部署
0 元
代码管理 + CI/CD：GitHub
私有仓库免费，Actions 每月 2000 分钟，代码托管、自动测试、自动部署一条龙。
提示：Actions 跑 Windows/macOS 会按 2 倍消耗分钟数，尽量用 ubuntu 跑。
部署托管：EdgeOne Makers
腾讯全栈应用部署平台，永久免费：40 个项目、云函数 100 万次/月、KV 和 Blob 存储各 1GB。国内节点访问速度比 Vercel、Cloudflare Pages 快不少。
提示：个人网站 / API / 全栈小应用都能放，静态页和云函数一套搞定。
3数据与存储
0 元
数据库：Supabase
一站式后端：免费 500MB PostgreSQL 数据库，自带用户认证（邮箱/手机验证码）、文件存储和 Edge Functions，全栈项目开箱即用。
提示：超限会暂停项目，定期清一下测试数据；适合 MVP 起步。
对象存储：七牛云 / 又拍云
七牛云实名用户每月 10GB 存储 + 10GB CDN 回源；又拍云联盟计划，网站底部挂个 Logo 就领 15GB CDN/月。存图片、静态资源完全够用。
提示：图片/文件建议走对象存储，别堆在服务器或 Git 仓库里。
4域名与证书
29 元起/年
域名：国内云服务商
29 元/年起，整个方案唯一花钱的地方。注册需实名，放国内服务器还要做 ICP 备案（约 2-3 周）。
提示：网站放 GitHub Pages / EdgeOne 海外节点可免备案，先用起来再补。
SSL 证书：Let's Encrypt
免费证书，90 天有效，配合 acme.sh 自动申请和续期，一次配置后就不用管了。
提示：GitHub Pages 自带 HTTPS，绑自定义域名也能一键配好证书。
5运营监控
0 元
错误监控：Sentry
自动捕获前后端报错，免费版每月 5000 错误事件，几行代码接入，支持几十种语言和框架。
提示：配置 Source Map 后，线上报错能直接定位到源码行。
流量统计：百度统计 / 51.la
百度统计完全免费，适合 SEO 关键词分析；51.la 免费版每月 300 万 PV，量大也扛得住。
提示：两个都埋，数据可互相印证。
邮件发送：Resend
国外开发者邮件服务，API 简洁、文档友好，免费版每月 3000 封（日限 100 封），适合验证码、通知类邮件。
提示：日限 100 封，群发营销不适合，做交易邮件刚好。
6办公协作
0 元
设计工具：即时设计
国产 UI 设计工具，个人版永久免费，核心功能无阉割，内置组件库和素材社区，可替代 Figma（Figma 国内访问要代理）。
提示：和开发对接可导出 CSS / 切图，个人项目够用。
文档协作：飞书 / Notion
飞书免费版支持 50 人以下团队，云文档、多维表格、日历齐全；Notion 不限页面数，适合个人知识库。
提示：对外分享用飞书文档链接，个人沉淀用 Notion 数据库。

三个常见场景怎么组

个人博客 / 作品集
GitHub Pages 托管 + 自定义域名 + Let's Encrypt 证书 + 百度统计 + Sentry，几乎零成本永久跑。
全栈 SaaS / 小程序后端
EdgeOne Makers 部署 + Supabase（数据库/登录）+ Resend（通知邮件）+ Sentry（报错）+ 七牛/又拍（图片），月度成本还是 0。
AI 应用
百炼/智谱/豆包 API 做模型层 + Dify 自托管做应用编排 + EdgeOne 前端托管，AI 应用也能白嫖起步。

更多值得收藏的免费工具

UptimeRobot：网站可用性监控，免费 50 个监控点，挂了第一时间邮件/微信通知。
TinyPNG：图片压缩，每月免费 500 张，给页面和 App 资源瘦身，加载更快。
Cloudflare：免费 CDN + DNS + DDoS 防护，配合 GitHub Pages 绑定自定义域名很稳。
Gitee 码云：国内代码托管，push/pull 速度比 GitHub 快，适合做 GitHub 的国内备份。
Dify：开源 LLM 应用平台，可自托管（免费），用拖拽搭 AI 应用、知识库问答。
腾讯问卷：免费表单，做用户调研、需求收集、内测报名很方便。
Lighthouse：Chrome 自带的性能检测，免费给网站打 SEO / 性能分，持续优化用。
