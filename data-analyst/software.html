软件用途费用下载 / 官网

🔧 安装后验证（打开 Anaconda Prompt 或终端输入）

国内加速：给 pip 换清华源，下载依赖包会快几十倍：

09安装小贴士与常见问题

🪟 Windows 安装 Anaconda 步骤

① 官网下载 64 位安装包（约 500MB）
② 双击运行，一路 Next，建议安装到 C 盘默认路径
③ 勾选「Add Anaconda3 to my PATH environment variable」（可选，便于终端调用）
④ 打开开始菜单里的 Anaconda Prompt，输入 conda --version 验证
⑤ 输入 jupyter notebook 启动，浏览器自动打开即成功

❓ 常见问题速查

下载慢 / 超时：用清华 TUNA 镜像站下载安装包，或给 pip/conda 换源
提示不是内部命令：说明没加入 PATH，重启终端；或直接用 Anaconda Prompt
装库报错：优先用 conda install 包名，再试 pip install 包名
MySQL 连不上：检查服务是否启动（服务管理器里 MySQL80），确认端口 3306 与密码

安全提醒：只从本页列出的官方网站/镜像下载。第三方下载站常捆绑广告软件，安装时如遇「附加安装」选项一律取消勾选。
