02数据分析师能力模型

硬技能决定你能不能做，软技能决定你能走多远。

🧠 硬技能（技术栈）

数据分析师的核心技术栈，学习路线按此展开：

Excel 数据处理 SQL 查询 Python（Pandas/NumPy） 统计学基础 数据可视化 BI 报表（Tableau / Power BI） A/B 测试 机器学习入门

💬 软技能（通用能力）

同样是面试与晋升的重要考察点：

结构化思维 业务理解力 沟通表达 数据敏感度 文档与汇报能力 好奇心和自驱力 团队协作

03职业发展路径

数据分析师的典型成长阶梯与横向发展可能。

📌 初级数据分析师

0–2 年

负责取数、出报表、数据清洗、日常监控，能回答「发生了什么」。掌握 Excel、SQL、基础 Python 与可视化即可胜任。

📈 中级数据分析师

2–4 年

独立承担专题分析，能回答「为什么发生」。熟练 A/B 测试、指标体系搭建、统计分析，能向业务输出结论与建议。

🚀 高级 / 专家方向

4 年+

三个主流分支：数据科学家BI / 数据产品数据分析管理岗——偏建模预测、偏工具产品化、偏团队与业务决策。
