流量传感器

用于测量管道中流体（液体 / 气体 / 蒸汽）的流速与累积流量，是能源计量、工业过程控制与水务管理中最关键的一类仪表。

量程比 10:1 ~ 100:1 精度 ±0.1% ~ ±2% 介质 液体 / 气体 / 蒸汽 输出 脉冲 / 4-20mA / RS485

01什么是流量传感器

Flow Meter / Flow Sensor —— 实时测量单位时间内通过截面的流体体积或质量。

📊

体积流量

单位时间内通过的流体体积（m³/h、L/min），受温度、压力与介质密度影响。

⚖️

质量流量

单位时间通过的流体质量（kg/h），与温度压力无关，贸易计量首选。

🧮

累积流量

对瞬时流量积分得到总量，用于水表、气表、加油机等计费场景。

02工作原理

主流流量测量技术一览。

🌀

涡轮式 脉冲计数

流体推动叶轮旋转，转速与流速成正比，磁电探头输出脉冲。精度高、量程宽，适合清洁低粘度液体。

🧲

电磁式 无压损

法拉第电磁感应：导电流体切割磁场产生电动势，正比于流速。适合污水、浆料、腐蚀性介质。

📡

超声波式 非接触

时差法测顺逆流声波传播时间差，或利用多普勒频移。可夹装在外管壁，适合大管径与腐蚀介质。

🌪️

涡街式 气体/蒸汽

卡门涡街：钝体后旋涡脱落频率与流速成正比。无可动部件，适合气体与饱和蒸汽测量。

🔥

热式 质量流量

加热元件的散热速率与质量流量相关，直接输出质量流量。适合低流量气体与微流量测量。

🧱

差压式 最传统

孔板 / 文丘里管产生压差，流量与压差平方根成正比。技术成熟、成本低，应用最广。

🛰️

科氏力式 精度之王

流体流经振动测量管产生科氏力引起相位差，直接测量质量流量，精度达 ±0.1%，用于贸易结算。

🛞

转子式

浮子/转子随流量升降，平衡位置指示流量。结构简单直观，适合小流量与实验室计量。

03关键技术参数

流量计选型要点。

参数说明典型值
量程比 Turndown最大 / 最小可测流量之比10:1 ~ 100:1
精度 Accuracy测量值与真值的偏差±0.1% ~ ±2% FS
可测介质导电性、清洁度、含气量等限制电导率 > 5 µS/cm（电磁式）
管径范围适用的管道通径DN2 ~ DN3000
温度 / 压力介质工况限制-40~200℃ / ≤ 25 MPa
压损传感器对管路的阻力电磁/超声 ≈ 0
输出信号脉冲、4-20mA、HART、Modbus频率 / 电流 / 总线

04应用场景

从家用燃气表到跨海管道。

🚰

水务管理

自来水厂、管网分区计量、智慧水务大表与小表。

⛽

石油化工

原油输送、化工原料配比、贸易交接计量。

🔥

能源计量

天然气、蒸汽、热力结算，碳排放核算。

🏢

暖通空调

冷热水流量、风机盘管计量、楼宇能耗管理。

🥤

食品饮料

灌装线、巴氏杀菌、CIP 清洗流量控制。

🏥

医疗器械

输液泵、呼吸机气体流量、血泵监测。
