流体传感器

测量流体物性参数的传感器家族：液位、粘度、密度、浊度、电导率、溶解氧…… 它们共同构成流体状态监测的"五官"。

液位 ±1 mm 粘度 0.2 ~ 10⁶ cP 浊度 0 ~ 4000 NTU 密度 ±0.1 kg/m³

01什么是流体传感器

Fluid Sensor —— 针对流体（液体 / 浆料 / 气体）各类物理化学参数进行检测的传感器集合。

📏

液位 / 料位

储罐、反应釜、水池中的液面高度或固料界面位置，是过程控制的基础参数。

🍯

粘度

流体的内摩擦特性，直接影响输送能耗、混合效果与产品质量。

⚖️

密度 / 浓度

单位体积质量，可换算溶液浓度、API 度、Brix 糖度等工艺指标。

🌫️

浊度

悬浮颗粒对光的散射程度，水质监测的核心指标（NTU / FTU）。

⚡

电导率

溶液导电能力，反映离子浓度，用于水质与清洗验证（CIP）。

🫧

溶解氧 / 余氯

水质生化指标，用于污水曝气控制、饮用水消毒监测。

02工作原理

各类流体参数的主流检测技术。

📏

液位检测

  • 静压 / 差压式：液柱压力换算液位
  • 超声波 / 雷达：回波测距，非接触
  • 电容式：介电常数变化
  • 浮子 / 磁翻板 / 光电：开关量与连续量
🍯

粘度检测

  • 旋转式：转子扭矩与粘度成正比
  • 振动式（音叉）：阻尼衰减反映粘度
  • 毛细管式：压差-流量关系（Poiseuille）
⚖️

密度检测

  • 振动管式：谐振频率随密度变化，精度最高
  • 浮力式：浮子浸没深度与密度相关
  • 差压式：两点压差 / 液位换算密度
🌫️

浊度检测

  • 90° 散射光式：ISO 7027 标准，最常用
  • 透射光式：光强衰减，适合高浊度
  • 激光散射：低浊度高灵敏
⚡

电导率检测

  • 两电极式：简单，易极化
  • 四电极式：消除极化，量程宽
  • 电感式：无接触，耐腐蚀
🫧

溶解氧检测

  • 极谱式（Clark 电极）：电流法
  • 荧光淬灭式：免维护，无耗氧

流体传感器选型要点。

参数说明典型值
液位量程可测液位高度范围0.1 ~ 100 m
液位精度雷达 / 伺服可到毫米级±1 mm ~ ±10 mm
粘度范围可测粘度跨度0.2 ~ 10⁶ cP
密度精度振动管式最佳±0.1 kg/m³
浊度量程饮用水到污水全量程0 ~ 4000 NTU
介质兼容性耐腐蚀 / 耐高温材料SS316L / PTFE / 陶瓷
防护等级水下 / 户外安装能力IP68（探头）

04应用场景

从污水厂到啤酒发酵罐。

🏭

污水处理

曝气池溶解氧、出水浊度、池体液位监测。

🧪

化工制药

反应釜液位与密度、溶剂电导率、中间体粘度在线监控。

🍺

食品酿造

啤酒原麦汁浓度、发酵液浊度、牛奶密度与脂肪检测。

⛽

油品储运

油罐液位与密度、油水界面、管线粘度监测。

🚢

船舶压载水

压载舱液位、排放水浊度与生物指标。

🌊

水文环保

河流湖泊水位、水库浊度、地下水电导率在线监测。
