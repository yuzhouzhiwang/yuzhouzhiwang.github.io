📚 推荐资源 · 面试导向
📕 《模拟电子技术基础》 教材
童诗白/华成英（清华），国内模电首选教材。重点：运放虚短虚断、三极管放大、反馈。B站有配套课程，配合「数模电仿真【书籍】」落地。
📗 《数字电子技术基础》 教材
阎石（清华），数电体系最全。重点：逻辑门、组合/时序电路、触发器。配合「图灵完备」游戏理解逻辑门物理实现。
📘 《电路》邱关源 前置
KVL/KCL、戴维南、一阶RC，数模电的数学地基。面试问「分压」「滤波」都从这里来，薄弱的章节配B站石群《电路》80讲。
📙 《晶体管电路设计》上下册 实操
铃木雅臣（日），从实际电路反推原理，最贴近工程。面试讲项目时「为什么选这个拓扑」的底气来源。
📓 《你好，放大器》 速成
杨建国（西电），运放应用实战书，短平快、面试够用。你已有20倍放大压力传感器电路经验，正好对照深化。
📔 《运算放大器权威指南》 工具书
TI官方经典，随查随用不硬啃。做数控电源的采样/基准电路时翻对应章节。
⚙️ 《FreeRTOS实时内核使用指南》 手册
Amazon官方中文手册，任务/队列/信号量/内存管理随查随用。配套B站韦东山FreeRTOS视频打基础，周二理论+周日实战落地。
🖥 LVGL 官方文档 + 移植教程 官方
对象树/控件/事件回调/动画以 docs.lvgl.io 为准；移植参考 lv_port_stm32，智能面板项目里边移植边学。

🛠 0到1项目推荐（按优先级）
⚡ 数控直流电源 主推
STM32F103C8 + DC-DC，0.1V步进调压。覆盖电源设计+运放+ADC+PWM+显示，升级为FreeRTOS四任务（采样/控制/显示/按键），与你48V→5V电源需求同源，面试讲「电源」话题直接有料。
完整工程参考（含KEIL）→
🖥 智能控制面板 主推·MCU项目
STM32F103RCT6 + FreeRTOS + LVGL + 3.5寸TFT触摸。一个项目拿下 MCU/RTOS/LVGL 三个招聘关键词：多任务（UI/触摸/采集）+图形界面+触摸交互，与传感器项目同思路，可升级HMI作品。
LVGL官方文档→ 官方移植参考→
🔧 ST-Link V2.1 调试器 次推
STM32F103C8 + USB，经典复刻。做出来后天天自用调试，面试能讲原理图+固件烧录。「攻城狮神木」开源作品。
立创开源地址→
📡 STM32 逻辑分析仪 备选
STM32 + PulseView，SUMP协议，成本百元内。覆盖GPIO采样+USB通信+上位机，工具型项目，讲「调试能力」时加分。
GitHub开源→
🌡 环境监测站 备选
DHT22/BMP280/OLED + ESP8266上传云端。完整传感器信号链+无线通信，与你压力传感器项目同思路，可升级为「传感器数据上云」作品，也可并入智能控制面板做采集任务。

🎯 面试高频考点（八股背诵清单）
💬 C语言必背 P0
  • 指针与内存：野指针/悬垂指针、堆栈区别
  • volatile / static / const 用法与场景
  • 内存对齐、大小端、位操作
  • 宏与函数的取舍
🔩 MCU与外设必背 P0
  • 中断响应流程、抢占/响应优先级
  • 定时器：PWM/输入捕获原理
  • UART/SPI/I2C 对比（几根线/速率/时序）
  • DMA原理、看门狗
🔌 模数电必背 P1
  • 运放虚短虚断、同相/反相放大
  • ADC采样：分辨率/基准电压/换算
  • RC滤波、分压电路
  • 数字逻辑：门电路/触发器/时序
🗂 项目与表达必练 P0
  • STAR法则写简历：场景/任务/行动/结果
  • 1分钟自我介绍（背熟）
  • 项目深挖：架构/数据流/调试闭环
  • 「现象→定位→解决」讲调试故事
⚙️ RTOS 必背 P0
  • 任务状态机、抢占式调度 vs 时间片
  • 队列 vs 信号量 vs 互斥量 区别
  • 优先级反转与解决（优先级继承）
  • 中断与任务通信（FromISR API）
🖥 LVGL 入门 P1
  • 对象树/控件/事件回调
  • 屏幕切换与刷新机制（脏矩形）
  • 与RTOS配合（tick时基/任务划分）
  • 触摸交互（XPT2046）
