P0 必背高频 2-3周拿下 · 所有岗位必问 先背熟再投递，打卡页周三「面试八股背诵」+周日「八股刷题」就是为它服务的。
C语言 必背出现率 90%+
学什么
  • 指针：指针数组/数组指针/函数指针
  • 内存：堆/栈/静态区、malloc/free配对
  • volatile / static / const 修饰符
  • 内存对齐、大小端、位操作
面试怎么问
  • volatile 的作用？举例
  • const int* 与 int* const 区别
  • 内存泄漏怎么排查
  • static 在函数内/外的区别
怎么练
  • 打卡周三背 + 周日刷题
  • 牛客C语言刷题50道
  • 自己写个小程序跑指针实验
MCU 中断与定时器出现率 90%+
学什么
  • 中断响应流程：触发→入栈→ISR→出栈
  • 中断优先级管理（抢占/子优先级）
  • 定时器：计数/比较/PWM生成
  • 你的 HC32F005 ADT/Timer6 实战
面试怎么问
  • 中断里能不能调用 printf/延时？为什么
  • 两个中断同时来先执行谁
  • PWM 占空比怎么算的
  • 中断和轮询怎么选
怎么练
  • 拿 HC32F005 实际配一次定时器中断
  • 讲清你项目里 PWM/中断的配置
UART / SPI / I2C 对比出现率 85%+
学什么
  • 三协议：引脚数/全双工/速率/时序
  • UART：起始位/数据位/停止位/波特率
  • SPI：SCK/MOSI/MISO/CS、4种模式
  • I2C：SDA/SCL、地址、应答、上拉电阻
  • Modbus RTU（你已有基础）
面试怎么问
  • UART/SPI/I2C 各自几根线、什么时候用
  • I2C 为什么要上拉电阻
  • SPI 四种模式怎么区分
  • 你项目里传感器用的什么协议
怎么练
  • 画一张三协议对比表背熟
  • 结合传感器项目讲清信号链
模数电基础出现率 70%+
学什么
  • 运放：虚短虚断、同相/反相放大
  • ADC：分辨率/基准电压/数值换算
  • RC滤波、分压电路
  • 逻辑门、计数器（数电）
面试怎么问
  • 12位ADC 分辨率多少？怎么换算电压
  • 同相放大增益公式？虚短虚断怎么用
  • RC低通滤波截止频率
  • 你压力传感器信号链怎么设计的
怎么练
  • 打卡周一「数电仿真」落地
  • 图灵完备游戏补逻辑基础
  • 重做一遍 20倍运放电路计算
P1 项目讲透 社招核心武器 · 边做边讲 面试官不看你列了多少项目，只看你能不能把一个项目从头到尾讲明白。每个项目备好3个「现象→定位→解决」故事。
数控直流电源（主推 0到1）本周启动
覆盖知识点
  • DC-DC 拓扑（Buck原理）
  • PWM 调压 + 反馈环路
  • ADC 采样 + 数码管/LCD显示
  • 运放（误差放大）
与你已有项目同源
  • 你的 48V→5V DC-DC 设计需求
  • STM32F103C8 + 0.1V步进
  • 参考：CSDN 开源方案
  • 周五+大周周六项目实操推进
面试讲法
  • 为什么选这个拓扑？
  • 输出电压不准怎么调？
  • 纹波大怎么解决？
  • 遇到最难的问题是什么？
ST-Link V2.1 调试器（0到1 备用）冬歇期做
覆盖知识点
  • USB 通信协议基础
  • 固件烧录流程（SWD）
  • PCB 设计 → 打样 → 焊接
开源参考
  • 立创开源广场「ST-Link V2.1」方案
  • 做出来日常开发自用+面试展示
压力传感器项目（已有 · 讲透）随时可讲
核心链路
  • XGZ040/GZP160-101S 传感器
  • 20倍运放放大（双极性输出）
  • ADC 采样 → 物理量换算
  • 零点校准方案
必须讲清
  • mV/V/kPa 灵敏度的物理意义
  • 内部基准 1.5V/2.5V 怎么选
  • ADC数值↔压力值换算公式
P2 加分可选 有余力再补 · 差异化亮点 P0/P1 稳定后再投入，多一项能讲的能力就多一分竞争力。

你的优势

  • 工业类岗位（MES/电子）会加分
PCB 设计规范项目驱动

  • 接地策略
