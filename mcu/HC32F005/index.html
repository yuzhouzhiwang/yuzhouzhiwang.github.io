EXAMPLE 01

gpio_output · GPIO 输出翻转点灯

官方 GPIO 例程：打开 GPIO 外设时钟，将 LED 引脚配置为输出并下拉，main 循环中每 1s 翻转一次 LED。
官方源码（example/gpio/gpio_output/source/main.c）
int32_t main(void)
{
    ///< LED端口初始化
    App_LedInit();

    while(1)
    {
        ///< LED点亮
        Gpio_WriteOutputIO(STK_LED_PORT, STK_LED_PIN, FALSE);
        delay1ms(1000);

        ///< LED关闭
        Gpio_WriteOutputIO(STK_LED_PORT, STK_LED_PIN, TRUE);
        delay1ms(1000);
    }
}

static void App_LedInit(void)
{
    stc_gpio_cfg_t stcGpioCfg;

    ///< 打开GPIO外设时钟门控
    Sysctrl_SetPeripheralGate(SysctrlPeripheralGpio, TRUE);

    ///< 端口方向配置->输出
    stcGpioCfg.enDir = GpioDirOut;
    stcGpioCfg.enPu  = GpioPuDisable;
    stcGpioCfg.enPd  = GpioPdEnable;

    ///< GPIO IO LED端口初始化
    Gpio_Init(STK_LED_PORT, STK_LED_PIN, &stcGpioCfg);
}

EXAMPLE 02

uart_int · UART1 中断收发

官方 UART 例程：P35 复用为 UART1_TX、P36 复用为 UART1_RX（GpioAf1），9600bps 偶校验，中断接收两字节并回显。与常见 8N1 应用完全兼容。
官方源码（example/uart/uart_int/source/main.c）
///< UART1 中断服务函数
void Uart1_IRQHandler(void)
{
    if(TRUE == Uart_GetStatus(M0P_UART1, UartRC))
    {
        Uart_ClrStatus(M0P_UART1, UartRC);
        u8RxData[1] = Uart_ReceiveData(M0P_UART1);
        u8RxFlg = 1;
    }
}

//串口引脚配置
static void App_PortInit(void)
{
    stc_gpio_cfg_t stcGpioCfg;
    DDL_ZERO_STRUCT(stcGpioCfg);
    Sysctrl_SetPeripheralGate(SysctrlPeripheralGpio,TRUE);

    ///<TX
    stcGpioCfg.enDir = GpioDirOut;
    Gpio_Init(GpioPort3, GpioPin5, &stcGpioCfg);
    Gpio_SetAfMode(GpioPort3, GpioPin5, GpioAf1); //P35 = UART1_TX

    ///<RX
    stcGpioCfg.enDir = GpioDirIn;
    Gpio_Init(GpioPort3, GpioPin6, &stcGpioCfg);
    Gpio_SetAfMode(GpioPort3, GpioPin6, GpioAf1); //P36 = UART1_RX
}

EXAMPLE 03

adc_norm_polling · ADC 单次轮询采样

官方 ADC 例程：将 P24 / P26 配置为模拟输入（AIN0 / AIN1），内部 2.5V 基准，主循环中轮询两通道转换结果。
官方源码（example/adc/adc_norm_polling/source/main.c）
static void App_AdcPortInit(void)
{
    Sysctrl_SetPeripheralGate(SysctrlPeripheralGpio, TRUE);
    Gpio_SetAnalogMode(GpioPort2, GpioPin4);  //P24 -> AIN0
    Gpio_SetAnalogMode(GpioPort2, GpioPin6);  //P26 -> AIN1
}

static void App_AdcInit(void)
{
    Sysctrl_SetPeripheralGate(SysctrlPeripheralAdcBgr, TRUE);
    Adc_Enable();
    Bgr_BgrEnable();

    stcAdcCfg.enAdcOpMode      = AdcNormalMode;      //单次采样
    stcAdcCfg.enAdcClkSel      = AdcClkSysTDiv1;
    stcAdcCfg.enAdcRefVolSel   = RefVolSelInBgr2p5;  //内部2.5V参考
    Adc_Init(&stcAdcCfg);
}

while(1)
{
    delay1ms(1000);
    stcAdcNormCfg.enAdcNormModeCh = AdcExInputCH0;   //通道0 P24
    Adc_ConfigNormMode(&stcAdcCfg, &stcAdcNormCfg);
    Adc_Start();
    while(FALSE != Adc_PollBusyState());
    Adc_GetResult(&u16AdcResult);
}

07 · NOTES

使用说明与注意事项

来自 HC32F003/005 用户手册的关键注意点，以及本页数据来源。

电源与内核供电：VCC（AVCC/DVCC）1.8V~5.5V，AVCC 与 DVCC、AVSS 与 DVSS 芯片内部相连。VCAP 为内核 LDO 输出，需外接 ≥4.7μF 电容到地，不可外接电源。
复位：RESETB（P00）低有效复位输入，复位后默认配置为输入；该引脚仅支持数字输入功能。
QFN 散热焊盘：QFN20 / QFN24 封装底部 Exposed Thermal Pad 需连接到 DVSS（地）。QFN24 型号（HC32F005D6UA）有 4 个 NC 引脚。
工作模式：运行 / 休眠 / 深度休眠三种模式。休眠时 CPU 停止、外设运行；深度休眠时高速时钟停止，ADC、UART、SPI、I2C、定时器等外设停止（VC、LVD、WDT、GPIO 中断可唤醒）。
模拟基准：ADC 参考电压可选内部 2.5V（BGR 带隙基准）或外部 AVREF（P36），当 AVDD < 3V 时需选用相应参考配置。
官网 DDL：《HC32F003/005 设备驱动库 DDL》配合 Keil MDK / IAR 使用，例程位于 example 目录，各例程 main.c 在 <模块>/<例程>/source/main.c。
