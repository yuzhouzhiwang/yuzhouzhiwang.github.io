芯片特性

  • 支持 ISP 在线编程
  • 低功耗 Idle/ADC-Noise/Power-Down

示例代码 · GPIO 闪烁

ATmega328P · main.c
// Arduino UNO / ATmega328P - GPIO 闪烁
void setup() {
  pinMode(13, OUTPUT);  // PB5 内置LED
  Serial.begin(9600);
  Serial.println("ATmega328P Start");
}
void loop() {
  digitalWrite(13, HIGH);
  delay(500);
  digitalWrite(13, LOW);
  delay(500);
}
