EXAMPLE 01

GPIO_LED_Toggle · 端口翻转点灯

官方 GPIO 例程：初始化 PA4 / PA5 / PA6 为推挽输出，每 100ms 翻转一次（MiniBoard 开发板对应 LED）。
官方源码（gpio_led_toggle.c）
// GPIO_Configure(): 配置 LED 引脚为输出
void GPIO_LED_Toggle_Sample(void)
{
    printf("\r\nTest %s", __FUNCTION__);
    GPIO_Configure();

    while (1)
    {
        GPIO_IO_Toggle(GPIOA, GPIO_Pin_4);
        GPIO_IO_Toggle(GPIOA, GPIO_Pin_5);
        GPIO_IO_Toggle(GPIOA, GPIO_Pin_6);
        PLATFORM_DelayMS(100);
    }
}

EXAMPLE 02

UART_Interrupt · 串口中断收发

官方 UART 例程：初始化 UART1（115200bps），中断接收 10 字节后回显。体现 MM32 标准库 UART 中断收发流程。
官方源码（uart_interrupt.c）
void UART_Interrupt_Sample(void)
{
    printf("\r\nTest %s", __FUNCTION__);
    UART_Configure(115200);
    UART_RxData_Interrupt(10);

    while (1)
    {
        if (0 != UART_RxStruct.CompleteFlag)
        {
            UART_TxData_Interrupt(
                (uint8_t *)UART_RxStruct.Buffer, UART_RxStruct.Length);
            while (0 == UART_TxStruct.CompleteFlag) {}
            UART_RxData_Interrupt(10);
        }
    }
}

TIM3_PWM_Output · 定时器 PWM 输出

官方 TIM3 例程：16 位通用定时器配置 PWM 输出（4 路独立通道），支持中心 / 边沿对齐模式。MiniBoard 上 LED 呼吸灯即基于此。
官方源码（tim3_pwm_output.c）
void TIM3_PWM_Output_Sample(void)
{
    printf("\r\nTest %s", __FUNCTION__);
    TIM3_Configure();

    while (1)
    {
        PLATFORM_LED_Toggle(LED1);
        PLATFORM_DelayMS(100);
    }
}

07 · NOTES

使用说明与注意事项

来自 MM32L0020 数据手册的关键注意点，以及本页数据来源。

启动模式：BOOT0 引脚与 nBOOT1 选择位决定从片内 Flash / 系统存储区 / SRAM 启动；系统存储区 Bootloader 可经 UART1 对片内 Flash 重新编程（ISP）。
工作电压：VDD 1.8V~5.5V，其中 1.8V~2.0V 不支持待机模式（Standby）。无独立 VDDA 引脚，VDDA 与 VDD 芯片内部相连。
低功耗模式：支持低功耗运行 / 睡眠 / 低功耗睡眠 / 停机 / 深度停机 / 待机六种模式；待机模式需 WKUP 引脚上升沿、NRST 复位或 IWDG 复位唤醒。
QFN20 散热焊盘：QFN20 的 Exposed Pad（底部散热焊盘）为 VSS，需可靠接地。TSSOP20 与 QFN20 引脚编号不同，焊接 / 画板请严格对照封装图。
调试接口：SWD 两线调试：SWDIO=PA13、SWCLK=PA14。I/O 均可映像到 16 个外部中断线（EXTI）。
官网例程：《MM32L0020 库函数与例程》需配合 Keil MDK / IAR 与 Keil Pack / IAR Pack 使用，例程基于标准外设库（含库函数与寄存器两套操作）。
